# Technology Stack

## Core Framework & Runtimes
- **Framework**: React 18 with TypeScript (`frontend/package.json`)
- **Build Tool / Bundler**: Vite 5 (`frontend/vite.config.ts`)
- **Language**: TypeScript (`tsconfig.json`, `tsconfig.app.json`, `tsconfig.node.json`)

## Frontend Libraries & UI
- **Routing**: `react-router-dom` v6
- **Icons**: `lucide-react`
- **Utilities**: `classnames`, `date-fns`, `uuid`

## Backend & Database
- **BaaS Platform**: Supabase (`@supabase/supabase-js`)
- **Database Engine**: PostgreSQL with RLS (Row Level Security)
